# Calendar browser dependencies

Bundled locally so the calendar does not require CDN access at runtime.

- FullCalendar Standard 6.1.19: https://www.npmjs.com/package/fullcalendar/v/6.1.19
- FullCalendar Korean locale 6.1.19: https://www.npmjs.com/package/@fullcalendar/core/v/6.1.19
- FullCalendar Luxon 3 connector 6.1.19: https://www.npmjs.com/package/@fullcalendar/luxon3/v/6.1.19
- Luxon 3.7.2: https://www.npmjs.com/package/luxon/v/3.7.2

All are MIT licensed. See the accompanying license files. The FullCalendar
connector is also covered by the FullCalendar license.

Luxon and the connector make Asia/Seoul independent of the browser's timezone.
