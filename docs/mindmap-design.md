# 마인드맵 · 프로그래밍 및 서비스 구조 편집 요구사항

## 저장

SQLite에 맵, 노드, 관계, 배치, 사용자 정의 유형과 스타일을 저장한다.

## 편집 요구사항

- 사용자 정의 유형을 추가·편집할 수 있다. 초기 유형은 화면, API, Controller, Service, Mapper, 테이블, 테스트다.
- 유형별 기본 스타일로 모양, 배경색, 글자색, 선, 아이콘을 지정할 수 있다.
- 개별 노드에서 유형의 기본값을 덮어쓰거나 기본 스타일로 되돌릴 수 있다.
- 호출, 참조, 조회, 검증 등의 관계를 추가하고 선 종류·방향·라벨을 변경할 수 있다.
- 전체화면, 확대·축소, 화면 맞춤, 100% 보기를 제공한다.
- 캔버스는 마우스로 잡아 끌어 이동할 수 있고, 휠과 터치 조작도 지원한다.
- DOT, Mermaid mindmap, Mermaid flowchart를 공통 노드·관계 모델을 거쳐 가져오고 내보낸다.
- 원본의 전체 정보는 SQLite에 유지하고, 외부 형식으로 표현되지 않는 속성은 변환 시 안내한다.

## 화면 구성

왼쪽에 저장 맵, 가운데에 캔버스와 편집 도구, 오른쪽에 노드·관계·유형·스타일 설정을 둔다.
자주 쓰는 도구는 상단 도구 모음에, 문맥에 따른 도구는 우클릭 메뉴에도 배치한다.

## 구현 및 사용

`마인드맵` 메뉴에서 서비스 예시를 편집하거나 새 맵을 생성한다. 상단 저장 버튼 또는 캔버스 안에서 Ctrl+S로 저장한다. 자동 저장은 하지 않는다. 맵 교체 시 저장되지 않은 변경을 확인한다.

- 화면: `app/pages/mind_map.py`, 로컬 편집기: `app/common/mindmap.js`.
- 저장: 기존 대시보드 SQLite의 `mind_maps`, `mindmap_types` 테이블. 맵 저장은 revision을 검사하여 다른 화면의 변경을 덮어쓰지 않는다.
- 사용자 정의 유형의 기본 스타일은 공통으로 저장되며, 노드의 직접 지정 스타일이 우선한다.
- 계층은 노드 드래그로 재배치한다. 자유 좌표 배치 대신 Mind Elixir 트리 배치를 사용하며, 확대율과 캔버스 이동 위치를 함께 저장한다.
- Tab 하위 노드, Enter 형제, Delete 하위 계층 삭제, Ctrl+Z 실행 취소, Ctrl+Y 다시 실행. 입력 필드에서는 해당 입력 동작을 유지한다.

## 변환 범위

DOT graph/digraph, 일반 노드·연결과 subgraph를 지원한다. subgraph는 그룹 노드가 된다. Graphviz 엔진 설치는 필요 없다. 복잡한 DOT 배치·스타일·집합 간 연결은 지원하지 않는다.

Mermaid는 mindmap의 공백 들여쓰기와 flowchart/graph LR·RL·TB·TD·BT를 지원한다. flowchart는 한 줄에 한 선언 또는 연결 체인을 작성하며, `-->`, `---`, `-.->`, `==>`, `<-->`, `|관계 이름|`을 지원한다. class/style/click 등의 선언은 경고와 함께 제외한다. 원본의 모든 Mermaid 문법을 지원하는 파서는 아니다.

순환·다중 부모·분리된 그래프는 대표 계층과 추가 관계로 변환한다. 외부 출력에는 KJA 메타데이터를 함께 기록하여 다시 가져올 때 노드 유형·스타일·관계를 복원한다. 일반 Mermaid mindmap 뷰어에서는 추가 관계가 보이지 않지만 KJA_BOARD로 다시 가져오면 복원된다. 공유용 원본 보존에는 JSON을 권장한다.

입력 제한은 UTF-8 2MB, 2,000노드, 5,000관계, 계층 깊이 100이다. 편집 자원은 로컬 번들이므로 실행 중 CDN이 필요 없다.

## 노드 복사·붙여넣기 단축키

- 노드 클릭으로 선택, Ctrl+클릭으로 다중 선택, 캔버스에서 Ctrl+A로 전체 선택한다.
- Ctrl+Shift+C 또는 Ctrl+C로 선택 노드와 하위 계층을 복사한다. 대상 노드를 클릭하고 Ctrl+Shift+V 또는 Ctrl+V를 누르면 그 아래에 복제한다.
- 노드 우클릭 메뉴의 **복사**, 대상 노드 우클릭 메뉴의 **붙여넣기**로도 같은 동작을 실행한다.
- 이름·유형·설명·파일 경로·개별 스타일과 복사 범위 안의 추가 관계를 유지한다. 새 ID를 부여하므로 원본과 독립적으로 편집한다.
- 여러 부모·자식을 함께 선택해도 자식을 중복 복제하지 않는다. 범위 밖 노드로 향하는 관계는 복제하지 않는다.
- 같은 화면에서는 내부 노드 버퍼를 사용하므로 브라우저 클립보드 권한이나 HTTPS 없이도 동작한다. 다른 맵을 불러온 뒤에도 붙여넣을 수 있으며 새로고침하면 내부 버퍼가 초기화된다.
- 시스템 클립보드 기록은 브라우저에서 허용할 때 전용 JSON으로 수행한다. 다른 탭에서 처음 붙여넣을 때는 Ctrl+V를 사용한다. 시스템 클립보드를 사용할 수 없는 HTTP 환경에서는 탭 사이 복사를 보장하지 않는다.
- Ctrl+Z로 붙여넣기 취소, Ctrl+Y 또는 Ctrl+Shift+Z로 다시 실행한다. 붙여넣은 뒤 Ctrl+S로 저장한다.
- 이름·설명 등 입력 중에는 일반 텍스트 선택·복사·붙여넣기를 유지한다. Mac에서는 Ctrl 대신 Cmd를 사용한다.

노드 생성 ID도 내부망 HTTP에서 지원되는 `crypto.getRandomValues`로 만든다.

검증: `node --test tests/editor_shortcuts.mjs`

## Mermaid 전체화면 텍스트 복사

글자를 드래그해 선택하고 Ctrl+C로 복사한다. Ctrl+A는 다이어그램 전체 텍스트를 선택한다.
빈 공간 드래그 또는 Space를 누른 채 드래그하면 이동한다. Ctrl+휠 확대·축소와 Esc 닫기도 유지한다.

## 요약 (Summary)

노드를 선택하고 상단 **요약 추가** 또는 우클릭 메뉴의 Summary를 누른다. 여러 노드를 Ctrl+클릭으로 선택하여 묶을 수도 있다.
요약 글자·괄호를 클릭하면 오른쪽 **요약** 패널에서 이름과 선·글자 색상을 바꿀 수 있다. 글자 더블클릭은 직접 이름 수정, 선택한 상태에서 Delete는 요약 삭제다. 요약 삭제는 대상 노드를 지우지 않으며 실행 취소를 지원한다.
SQLite와 JSON에는 요약의 대상 범위·이름·스타일을 저장한다. DOT·Mermaid는 요약을 KJA 메타데이터로 보존하며 외부 뷰어에서는 요약 괄호가 표시되지 않는다.


## 노드 검색·바로 이동·관계 강조

편집기 위쪽 검색창에서 이름·유형·설명·파일 경로를 검색한다. 대소문자와 영문 전각 차이를 무시하며 공백으로 나눈 검색어를 모두 포함하는 노드를 찾는다. 결과 목록에서 노드를 클릭하거나 Enter/Shift+Enter, 위/아래 버튼으로 순환 이동한다. 캔버스에서 Ctrl+F(Cmd+F)는 노드 검색창으로 이동한다.

검색 대상은 접힌 노드를 포함한다. 이동 시 필요한 부모만 펼치고 노드를 선택하여 캔버스 중앙으로 이동한다. 펼침 상태는 다른 편집처럼 저장·실행 취소 대상이다. 검색어와 강조 상태 자체는 문서에 저장하지 않는다.

**연결 관계 강조**를 켜면 현재 선택 노드와 직접 연결된 노드·선이 강조된다. 들어오는 관계·나가는 관계·부모와 자식 계층을 포함하며, 그 너머의 간접 연결은 포함하지 않는다. 접힌 노드는 펼치거나 검색 이동으로 확인할 수 있다. 버튼을 다시 누르면 원래 스타일로 돌아간다.


## 노드 모양

기본 네 가지(둥근 사각형·사각형·캡슐·타원)에 마름모·원통·육각형·문서형을 추가했다. 유형·스타일의 **모양**은 해당 유형의 기본값이며, 노드의 **스타일 직접 지정 → 모양**에서 개별 노드를 덮어쓸 수 있다. 글자는 회전하지 않고 배경·테두리만 SVG로 그린다. 노드 모양과 개별 스타일은 SQLite 및 DOT·Mermaid의 KJA 메타데이터로 보존한다. 외부 DOT·Mermaid 뷰어에서 같은 모양을 재현하는 것은 보장하지 않는다.
